Quản lý cấu hình API và lựa chọn mô hình AI hỗ trợ học tiếng Anh.

⚙️ Lựa chọn Mô hình AI

Tích chọn để sử dụng OpenAI (ChatGPT). Bỏ tích để sử dụng Google Gemini.
Đang dùng: ♊ Google Gemini

♊ Cấu hình Google Gemini

Cách lấy Gemini API Key (Miễn phí):
  1. Truy cập Google AI Studio.
  2. Chọn Get API key ➔ Create API key và copy key.
Lưu trong chrome.storage.sync, chỉ gọi trực tiếp từ trình duyệt của bạn.
Mặc định: gemini-3.1-flash-lite

🤖 Cấu hình OpenAI

Cách lấy OpenAI API Key:
  1. Truy cập OpenAI API Keys.
  2. Đăng nhập và chọn Create new secret key.
Key được lưu an toàn trong tiện ích của bạn.
Mặc định: gpt-4o-mini (Gợi ý: gpt-4o-mini, gpt-4o).
