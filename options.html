📌 Hướng dẫn lấy Gemini API Key:

  1. Truy cập Google AI Studio (aistudio.google.com).
  2. Đăng nhập tài khoản Google và chọn Get API key / Create API key.
  3. Sao chép (copy) API key vừa tạo.
  4. Dán vào ô Google Gemini API Key ở mục Cấu hình bên dưới rồi chọn Lưu để bắt đầu sử dụng.
Key được lưu trong chrome.storage.sync, chỉ dùng để gọi trực tiếp Google Gemini API từ trình duyệt của bạn.
Mặc định: gemini-3.5-flash-lite (Gợi ý: gemini-3.5-flash-lite, gemini-2.5-flash, gemini-2.0-flash, gemini-1.5-flash)
